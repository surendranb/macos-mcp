Give your agent hands on your Mac.

Get started

~60 seconds
1 · Install

One command

Works with Claude Desktop, Claude Code, Cursor, Gemini CLI, OpenCode, any MCP client.

npm install -g @surendranb/macos-companion-mcp
2 · Configure

Point your client at it

Or use npx -y and skip the install entirely.

{
  "mcpServers": {
    "macos": {
      "command": "npx",
      "args": ["-y", "@surendranb/macos-companion-mcp"]
    }
  }
}
3 · Grant access

One-time permissions

Launch Mail, Calendar, Notes, and Reminders once so Apple's permissions are in place. Allow camera/microphone in System Settings if you use sensing tools.

What you can ask

it just works

"Check my calendar for a free 30 minutes tomorrow afternoon and book a dentist visit."

→ Finds a gap, creates the event, reminder set. You confirm.

"Summarize my unread email, then reply to anything urgent."

→ Reads Mail.app, drafts a digest, sends replies from your account.

"What did I listen to this week? Pull the transcript of that one episode."

→ Searches episodes, plays it, fetches the full transcript locally.
